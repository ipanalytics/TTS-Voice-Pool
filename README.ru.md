# TTS Voice Pool

_English version: [README.md](README.md)_

**Один вызов — несколько поставщиков речи.** Ключи ротируются, когда у одного кончилась квота;
дизайнерский голос откатывается на предустановленный, когда истекает; темп держится в пределах,
которые человек способен слушать; и каждая озвучка попадает в журнал расхода, чтобы бесплатный
тариф, начавший вдруг списывать деньги, не остался незамеченным.

## Обзор

Я запускаю автоматизированный ассистент, который говорит ежедневно — брифинги, оповещения, напоминания. У задач по расписанию некого спрашивать, когда голос отваливается, поэтому каждая ошибка, которая раньше требовала решения человека, стала решением, которое код принимает сам. Этот пакет обеспечивает ротацию ключей, откат голоса, контроль темпа и учет расходов.

## Архитектура

Пул реализует несколько механизмов для обеспечения надежного синтеза речи:

- **Ротация ключей с памятью**: Каждый ключ имеет состояние, отслеживающее, когда он последний раз сработал, когда отдыхает после ошибки 429 и мертв ли он окончательно. Ключи проверяются в порядке последнего успеха, поэтому здоровый пул сходится к одному рабочему ключу, а не перебирает их.

- **Управление откатом**: После ошибки 429 с ограничением частоты, ключи отдыхают 5 минут, вместо того чтобы бомбить их сразу или блокировать слишком долго. Отдыхающие ключи перемещаются в конец очереди, но все равно пробуются, если все ключи отдыхают.

- **Цепочка моделей с откатом**: Модели настроены в цепочке (по умолчанию: `gemini-2.5-flash-preview-tts`), чтобы при сбое одной система пробовала следующую. Цепочка определена в однострочном файле, что делает откаты тривиальными.

- **Механизм отката голоса**: Дизайнерские голоса, которые падают по причинам, отличным от квоты/смерти, пробуются еще раз с предустановленным резервным голосом. Ошибки квоты не маскируются повторной попыткой.

- **Учет стоимости и контроль бюджета**: Каждый успешный синтез записывается с количеством символов, продолжительностью, использованными токенами и теоретической стоимостью. Ежемесячный лимит бюджета предотвращает неожиданные расходы — как только лимит достигнут, последующие вызовы идут на бесплатный резервный движок.

- **Контроль темпа**: Артикуляция измеряется как количество символов, деленное на (общее время минус обнаруженная тишина). Если выше порога (по умолчанию 12.3 символа/с), аудио растягивается с помощью `atempo` до соблюдения лимита, с минимальным коэффициентом растяжения 0.72, чтобы избежать слышимой деформации.

## Особенности

- Интерфейс командной строки: `--check`, `--say`, `--say-file`, `--usage`
- Библиотечный интерфейс: `from tts_voice_pool import say`
- Пул ключей с постоянным состоянием
- Конфигурация цепочки моделей
- Ограничение темпа с растяжением аудио
- Журнал расходов с ежемесячной отчетностью
- Бесплатный откат через edge-tts
- Правильные коды возврата для задач cron

## Установка

```bash
git clone https://github.com/ipanalytics/TTS-Voice-Pool
cd TTS-Voice-Pool
python -m pip install -e ".[edge]"     # edge-tts — необязательный бесплатный откат
```

`ffmpeg` и `ffprobe` должны быть в `PATH`: они измеряют темп и кодируют контейнер. Никаких
других зависимостей выполнения — HTTP-вызовы используют стандартную библиотеку.

## Использование

```bash
# Базовое использование
tts-voice-pool --say "Доброе утро. В сегодняшнем списке три пункта." briefing.ogg

# Проверка доступных ключей
tts-voice-pool --check

# Просмотр статистики использования
tts-voice-pool --usage

# Обработка текста из файла
tts-voice-pool --say-file input.txt output.mp3
```

## Выводы/артефакты

Система создает несколько выходных файлов:

- Аудиофайлы в запрошенном формате (ogg, mp3, wav и т.д.)
- `~/.hermes/data/tts_pool_state.json` - состояния ключей с последним успехом, откатами и т.д.
- `~/.hermes/data/tts_pool_usage.jsonl` - строки JSON с логами каждого синтеза
- Временные файлы обработки, которые очищаются после обработки

## Конфигурация

| Настройка | Переменная окружения | Файл (в `$TTS_POOL_HOME/data`) | По умолчанию |
|-----------|----------------------|-------------------------------|--------------|
| Базовая директория | `TTS_POOL_HOME`, затем `HERMES_HOME` | — | `~/.hermes` |
| Пул ключей | `GEMINI_API_KEYS`, `TTS_POOL_KEYS_FILE` | `.gemini_tts_keys` | пусто |
| Голос по умолчанию | `TTS_POOL_VOICE` | `tts_pool_voice.txt` | `Kore` |
| Заметки доставки | — | `tts_pool_style.txt` | пусто |
| Множитель темпа | — | `tts_pool_tempo.txt` | `1.0` (ограничен 0.5–2.0) |
| Потолок темпа, символы/с | — | `tts_pool_max_rate.txt` | `12.3` (0 отключает) |
| Цепочка моделей | — | `tts_pool_model.txt` | `gemini-2.5-flash-preview-tts` |
| Месячный лимит, доллары США | — | `tts_pool_budget.json` (`{"cap_usd": 5}`) | `0` (без лимита) |
| Бесплатный резервный голос | `TTS_POOL_EDGE_VOICE` | — | `ru-RU-SvetlanaNeural` |
| Таймаут запроса, с | `TTS_POOL_TIMEOUT` | — | `90` |

## Эксплуатационные замечания

- Ключи API читаются при каждом вызове и никогда не записываются в файлы состояния, позволяя использовать разные схемы разрешений
- Период отката после ошибок 429 составляет 300 секунд (5 минут)
- Дизайнерские голоса, которые истекают, автоматически откатываются на предустановленные
- Темп речи измеряется без учета обнаруженной тишины (порог -35 дБ, минимум 0.35с)
- Минимальный коэффициент растяжения 0.72, чтобы избежать слышимой деформации от чрезмерного замедления
- Бесплатный резервный движок (edge-tts) гарантирует отсутствие тишины, когда все платные ключи не работают

## Область проекта

Этот пакет предоставляет маленький слой между "у меня есть несколько ключей и текст" и "выдается воспроизводимый файл", с прописанными путями отказов и бесплатным откатом, который не дает задачам по расписанию замолчать. Это не стриминговый синтезатор, не локальный запуск моделей, не клонирование голоса.

## Сценарии использования

- Планирование голосовых брифингов и уведомлений
- Автоматическая генерация подкастов
- Голосовые оповещения для систем мониторинга
- Любое приложение, требующее надежного TTS с механизмами отката
- Контролируемый по стоимости синтез речи с бюджетным контролем

## Ограничения

- Поддерживает только Gemini API для платного TTS и edge-tts для бесплатного отката
- Требует установки ffmpeg/ffprobe отдельно
- Нет стримингового синтеза - файлы генерируются полностью перед доставкой
- Обнаружение истечения срока действия дизайнерских голосов ограничено шаблонами сбоев
- Контроль бюджета опирается на точную оценку стоимости, а не на фактические данные выставления счетов

## Тестирование

```bash
python -m pytest -q      # 43 пройдено
python -m ruff check .   # чисто
```

Нет ни сети, ни звукового оборудования в тестах: HTTP подменяется, математика темпа проверяется
на известных числах, и каждый тест получает свой `$TTS_POOL_HOME`, так что прогон тестов не может затронуть
реальный журнал или файл ключей. Что тесты **не** доказывают: что данный ключ все еще
работает — именно для этого есть `--check`.
